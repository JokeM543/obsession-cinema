## GitHub Pages

This is a complete static site. `index.html` is at the repository root, with the `assets/` folder alongside it. No build step, dependencies, or server is required.

In Settings → Pages, select **Deploy from a branch**, **main**, and **/ (root)**. Keep `.nojekyll` in the root. All asset paths are relative and work under a GitHub project URL.
